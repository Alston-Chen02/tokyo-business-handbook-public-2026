公開版不含個人聯絡姓名、電話、原始Word、PDF或分房名單。導遊聯絡資訊由使用者自行在裝置填寫，使用localStorage儲存。

資料來源原始山善R1及JIMTOF行程，通關與注意事項由官方資料於2026/10/14查證。個人機票權益、每日集合及巡航預訂仍須與導遊確認。
